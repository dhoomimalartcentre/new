# Dhoomimal Art Centre — Website Prototype

A seven-page website prototype for Dhoomimal Art Centre, A-8 Connaught Place, New Delhi. The layout follows the Heynar Mastow editorial gallery design: small type, generous white space, a clean grid and thin rules. The content and images come from dhoomimalartcentre.com.

## Pages

| File | Page |
|------|------|
| `index.html` | Home: introduction, highlighted exhibitions, artists, blog, press |
| `artists.html` | All 39 represented artists, with a scrolling name strip |
| `exhibitions.html` | Recent and past exhibitions, plus the full archive since 2011 |
| `collection.html` | 22 available works, prices on request |
| `art-fairs.html` | Art Mumbai 2025 and India Art Fair 2013–2016 |
| `contact.html` | Email, phone, address, hours, Instagram |
| `about.html` | The gallery's history from 1936, across three generations |

## View it

Open `index.html` in any browser. There's no build step or install; each page is a single HTML file.

To publish it with GitHub Pages:

1. Upload these files to a GitHub repository, keeping `index.html` at the top level.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then pick `main` and `/ (root)` and save.
4. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Notes

- Images load directly from dhoomimalartcentre.com, so an internet connection is needed to see them.
- Each page works on desktop and phone. On phones the navigation collapses into a MENU button.
- The artist, exhibition and collection lists are each kept in one short list near the bottom of their page, so entries can be added or edited in one place.
- "Read more" buttons, artist cards and artworks currently open the matching page on dhoomimalartcentre.com.
